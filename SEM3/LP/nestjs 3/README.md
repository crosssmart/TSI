# Criar projeto NestJS
```
nest new nomeProjeto -t -g
```
## Flags
-t alias para --skip-tests 
-g alias para --skip-git

# Executar projeto pela primeira vez
```
npm i
npm run start:dev
```

# Executar projeto
```
npm run start:dev
```

# Criar CRUD de produto
```
nest generate res produto --no-spec
```

## Flags
res é um alias para resource
--no-spec é para não gerar arquivos de teste

# Instalando dependencias para validação de dados
```
npm i class-validator
npm i class-transformer
```
